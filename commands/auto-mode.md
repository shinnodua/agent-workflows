# auto-mode Command

## Usage

```txt
$auto-mode on|off|toggle|status
/auto-mode on|off|toggle|status
```

## Behavior

Use `.agents/skills/auto-mode/SKILL.md` as the source of truth. The command
persists the workspace-local setting with `workflows auto on|off|toggle|status`.
